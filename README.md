# Analyzing Panel Data: GSERM St. Gallen 2026

This is the Github repository for the 2026 GSERM-St. Gallen course *Analyzing Panel Data*. The course meets daily in St. Gallen from June 22-26, 2026. This repository contains information about the course, including the course syllabus, lecture slides, example data, example code, exercises, and (eventually) the final examination.
